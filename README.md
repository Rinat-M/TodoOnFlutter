# Простое Todo-приложение на Flutter

Данный проект создан для пробы пера на Flutter с использованием Dart.

## Используемые пакеты
1. Drift
2. Riverpod
3. Logger
4. Flutter Hooks
5. Hooks Riverpod
6. Intl
7. Flutter Localizations
8. Change App Package Name
